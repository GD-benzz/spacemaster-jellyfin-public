> 空间大师只做转码音频工作，Jellyfin 字幕 / 刮削 / 元数据 / 媒体库 / 用户记录等其它功能均不受影响。

> 这份文档讲**开源 / 闭源的边界**和法律依据。
> 想装的话请直接看 **[安装指南.md](安装指南.md)**，那里是完整的逐步教程。

## 这是什么

空间大师是一套给 Jellyfin 加装的空间声学校正工具：在 Jellyfin 转码时施加 PEQ（参数均衡）、几何延时对齐的空间音效调整工具。

接入方式是把容器内的 `ffmpeg` 换成一个转码壳脚本，转码壳注入音频滤镜后再调用真正的 ffmpeg。
**不修改 Jellyfin 本体、不换镜像、不动媒体库**，卸掉空间大师叠加层后 Jellyfin 即恢复原版。

集成层代码**开源可审计**；声学引擎由引擎程序 `sm_dsp_engine` 提供（随仓库分发）。

## What is this

SpaceMaster is a set of room-acoustics correction tools added to Jellyfin: it applies PEQ (parametric equalization) and geometric delay alignment as a spatial audio adjustment at Jellyfin transcode time.

The integration method replaces the in-container `ffmpeg` with a transcode-wrapper script; after the wrapper injects the audio filter, it calls the real ffmpeg.
**It does not modify Jellyfin itself, does not swap the image, and does not touch the media library.** Removing the SpaceMaster overlay restores Jellyfin to its original version.

The integration-layer code is **open source and auditable**; the acoustics engine is provided by the engine program `sm_dsp_engine` (distributed with the repository).
